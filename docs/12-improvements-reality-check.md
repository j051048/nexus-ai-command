# 12个改进必要性评估 - 基于实际项目需求

## ✅ 必须做（3项）

### 1. System Prompt 工程化 - 工具约束 ⭐⭐⭐⭐⭐
**必要性:** 极高

**真实痛点:**
```python
# 当前 Agent 经常做错事
用户: "查询客户123"
Agent: 执行 bash 命令 `cat customers.json | grep 123`  # 错误！
应该: 调用 get_customer(id="123") tool
```

**为什么必须做:**
- 我们有 30+ 工具，Agent 经常选错
- 没有明确约束，AI 会用 bash 绕过工具
- 导致数据不一致、权限绕过

**实施方案:**
```python
SYSTEM_PROMPT = """
## 工具使用规则（CRITICAL）
- 查询客户: 必须用 get_customer tool
- 创建订单: 必须用 create_order tool
- 禁止使用 bash 直接操作数据库
- 禁止使用 bash cat/grep 读取数据文件
"""
```

**实施成本:** 1天
**收益:** 工具使用准确率 +60%

```python
3. 不要说"让我来帮您"、"好的我理解"等废话
4. 保持简洁
"""
```

**实施成本:** 半天
**收益:** 用户满意度 +40%

### 3. 微压缩机制 ⭐⭐⭐⭐
**必要性:** 高

**真实痛点:**
- 长对话后 Token 成本暴涨
- 工具输出占用大量 Context

**实施方案:**
```python
def _micro_compact(messages):
    """移除 5 分钟前的工具输出"""
    cutoff = datetime.now() - timedelta(minutes=5)
    return [
        msg for msg in messages
        if not (msg.type == "tool" and msg.timestamp < cutoff)
    ]
```

**实施成本:** 2天
**收益:** Token 成本 -30%
