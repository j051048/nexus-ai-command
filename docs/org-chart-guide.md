# 组织架构管理使用指南

> 适用角色: 企业管理员 (Boss), 部门经理 (Manager)

Nexus AI Command 的组织架构管理模块不仅是一个静态的展示工具，它更是企业数字化治理的核心。通过可视化界面与 AI 助手的结合，您可以轻松管理复杂的组织关系。

## 1. 核心概念

### 1.1 部门生命周期
- **活跃 (Active)**: 正常运行的部门，可分配员工，出现在所有业务下拉菜单中。
- **已解散 (Dissolved)**: 部门已不存在。系统采用“软删除”机制，解散后的部门数据会被保留用于审计，但不再出现在员工编辑、商机分配等活跃业务场景中。

### 1.2 节点类型
- **根节点**: 通常是您的企业/组织名称。
- **部门节点**: 二级及以下分支，展示部门负责人及下属人数。

---

## 2. 可视化界面操作

### 2.1 访问路径
左侧导航栏 → **“组织架构”**。

### 2.2 主要交互
- **平移与缩放**: 使用鼠标滚轮缩放，按住左键拖拽画布。
- **节点拖拽**: 您可以手动微调节点位置以获得最佳视觉效果。
- **查看详情**: 点击节点可查看该部门的详细信息，包括成员列表、KPI 完成情况（部分版本支持）。
- **导出**: 点击右上角“导出图片”，可将当前架构图另存为 PNG。

---

## 3. 部门管理

### 3.1 创建部门
1. 点击“新增部门”按钮（或通过 AI 指令）。
2. 输入 **部门名称**。
3. 选择 **上级部门**（留空则为一级部门）。
4. （可选）指派 **部门负责人**。

### 3.2 解散（删除）部门
为了保证历史数据一致性，系统禁止直接物理删除已有员工关联的部门。
- 逻辑：点击“删除”或“解散” -> 状态变更为 `dissolved`。
- 自动清理：解散后，该部门将立即从“员工编辑”页面的部门下拉列表中消失。

---

## 4. 员工调动

您可以直接在组织架构中管理员工的归属：
1. 在“员工管理”中打开员工编辑界面。
2. 在“所属部门”下拉框中选择目标部门。
3. 保存后，组织架构图将自动实时更新（由于采用了 Supabase Realtime 机制）。

## 6. 常见问题 (FAQ)

**Q: 为什么我在员工编辑页找不到刚创建的部门？**
A: 请确保该部门状态为“Active”。如果是刚通过 API 导入的，请检查 `status` 字段是否正确。

**Q: 架构图显示的部门名称重复了怎么办？**
A: 系统已在 v2.1 版本中修复了此问题。系统现在会自动过滤掉 `dissolved` 状态的同名遗留数据。如果仍有重复，请在“部门管理”列表中手动清理同名的 Active 部门。

**Q: 组织架构能导出 PDF 吗？**
A: 目前支持 PNG 导出。如需 PDF，建议使用浏览器的“打印”功能并选择“另存为 PDF”。
