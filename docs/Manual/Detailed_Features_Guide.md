# 01 - AI 核心交互与治理 (Manual)

本章节介绍 Nexus AI Command 的“大脑”部分，即 AI 聊天、记忆溯源与模型治理。

---

## 1.1 全强化的 AI 聊天面板 (Enhanced AI Chat)
*   **入口**：侧边栏首项 [AI 聊天]。
*   **多模型切换**：
    *   **GPT-4o/Claude 3.5**：适用于复杂逻辑推理、代码编写、深度分析。
    *   **Gemini Pro 1.5**：适用于处理超长文档（如上传 500 页的标书）。
    *   **DeepSeek/O1**：适用于高性价比的常规任务。
*   **附件处理**：
    *   **上传文档**：支持 PDF/Word/Excel，上传后勾选“解析并入库”，AI 即可在对话中引用文件内容。
    *   **上传截图**：支持多模态分析，AI 可以识别 UI 设计图并提供修改意见。

## 1.2 记忆溯源与审计 (Memory Trace)
*   **核心功能**：点击对话右上角的“🔍 溯源”图标。
*   **使用方式**：
    *   查看 **Context Breakdown**：AI 告诉你它引用了哪几个客户、哪几个合同。
    *   **得分校验**：如果本地数据匹配度低（Score < 70），建议用户手动微调检索参数。

## 1.3 模型管理与成本治理 (LLM Management)
*   **功能点**：查看各部门、各项目的 Token 消费排行。
*   **熔断设置**：管理员可在后台设置“单日成本熔断额”，达到额度后自动暂停高成本模型调用。

# 02 - 业务运营与销售中心 (Manual)

涵盖从市场线索抓取到成交的全过程。

## 2.1 虚拟市场部 (VMD) - 核心功能
*   **线索抓取**：AI 定时扫描公开招标平台。
*   **邮件自动化**：
    1.  选择线索。
    2.  点击“生成开发信”。
    3.  AI 自动匹配线索与我们公司的“产品优势库”。
    4.  通过邮件网关一键发出。

## 2.2 投标分析 (Tender Analysis)
*   **操作流**：
    1.  上传招标 PDF。
    2.  AI 自动输出《投标可行性分析报告》。
    3.  包含：资质匹配度评分、竞争对手预判、预估利润率、合规风险警告。

## 2.3 销售大屏 (Sales Dashboard)
*   **核心指标**：漏斗周转率、客单价趋势。
*   **预测能力**：基于历史成交记录，AI 预测本月销售额及潜在流失大客户名单。

# 03 - 合同、财务与行政 (Manual)

## 3.1 智能合同审核 (Contract AI)
*   **使用方法**：
    1.  上传法务提供的合同初稿。
    2.  AI 自动比对《公司标准协议库》。
    3.  标记出“高风险条款”并在右侧给出修改建议。

## 3.2 流程与审批 (Workflow Designers)
*   **React Flow 可视化**：
    *   **入口**：设置 -> 工作流设计。
    *   **拖拽逻辑**：左侧拖入“角色（Role）”、“判定（Judge）”、“动作（Action）”。
    *   **调试逻辑**：设计完成后，可直接在设计器中点击“模拟运行”查看流程走向。
