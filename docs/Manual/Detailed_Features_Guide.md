# Nexus AI Command 用户功能指南

本指南面向科学仪器企业的销售、售前、市场、项目和管理人员。默认操作方式是“在业务页面查看事实，在助手中下达自然语言任务”，用户不需要选择模型或理解 Agent 内部节点。

## 1. 第一次使用

首次登录会进入简短引导：

1. 填写公司名称、主营仪器谱系和目标市场。
2. 上传公司介绍、产品参数、仪器手册、应用案例、竞品资料、法规和历史方案。
3. 等待资料显示“可检索”，再确认产品线和事实边界。
4. 选择生成第一份客户方案或启动投标审阅。

支持 PDF、DOCX、PPTX、XLSX、TXT 和 Markdown。资料应使用清晰文件名并保留版本；参数、案例和政策优先上传原始来源。

## 2. 企业资料

入口：侧边栏“企业资料”。

- 搜索资料、查看入库状态、分类、来源和可信度。
- 资料未完成入库时可查看状态并重试，不应立即判断为“知识库不存在”。
- “让 AI 检查缺口”会按产品、手册、案例、竞品、法规和历史方案给出最值得补充的资料。
- 关系洞察位于二级标签，用于查看实体联系，不取代企业文档库。

提问时可以直接说：“只参考 FD-F 升级换代方案和食品安全检测仪产品手册，为成都某客户写 3000 字方案。”生成前仍需人工确认关键资料和外部承诺。

## 3. AI 助手

助手可以常驻侧栏、调整宽度或在移动端以抽屉打开。推荐直接描述目标、对象、限制和交付格式，例如：

> 根据当前客户、预算 30 万、食品检测场景和已选企业资料，先列证据缺口，再生成可编辑 Word 方案。

界面默认展示当前阶段、证据和待确认项，不展示内部思维链。高风险写入或外发会先给出预览，只有用户确认后执行。

生产聊天模型由平台统一管理，当前强制使用 `deepseek-v4-flash`。普通用户无需在每次任务前选模型；管理员可查看成本、失败和结构化 trace。

## 4. 方案作战

入口：“客户与项目”或 `/growth/solutions`。

六阶段工作流：

1. **需求**：关联客户，补齐行业、地域、样品、检测目标、预算、时间和验收要求。
2. **证据**：选择企业资料，核对型号、参数、案例、政策和竞品依据。
3. **配置**：形成基础、推荐、旗舰三档组合，检查价格、毛利、兼容性和交付约束。
4. **撰写**：按客户背景、需求、总体方案、参数优势、竞品对比、案例、实施与售后生成章节。
5. **复核**：检查事实、证据、承诺、字数、结构和人工审批状态。
6. **交付**：下载 Word、PDF 或 Excel，并在成果中心保留版本。

证据、预算或承诺未通过时不会开放正式外发，系统会说明需要补什么。

## 5. 投标作战

入口：`/growth/tenders`，旧 `/tender-analysis` 入口保持兼容。

上传招标 PDF/DOC/DOCX 后，AI 先做否决项、资质、评分点、技术偏离和证据缺口诊断，再生成应答矩阵、章节草稿和质量复核。系统不会未经确认直接发送或签章。

审阅报告可导出 PDF；完整投标成果应通过精品成果链路和人工定稿。

## 6. 精品成果与下载

当 AI 回复已包含足够业务内容时，消息下方会出现“制作精品成果”：

1. 选择成果类型、名称、企业资料和 Word/PDF/Excel 格式；PNG 位于旁边的快速导出菜单，不进入深度成果任务。
2. 确认 AI 只能引用企业资料，缺失事实会标记“待核验”。
3. 系统在后台重新检索、规划、生成、核验、修复和排版；耗时取决于资料量和模型服务，页面会持续显示阶段与进度。
4. 通过质量门的文件可立即下载；未通过的结果只作为审核草稿。

页面右上角“成果”是统一成果中心，可查看任务状态、质量分、证据、版本、来源页面并再次下载。刷新或切换页面不会丢失持久化成果。

## 7. 今日作战、CRM 与 VMD

- “今日作战”按业务价值、时点和证据完整度列出少量优先行动。
- CRM 维护客户 360、联系人、机会、项目和下一步；AI 可生成跟进建议和邮件草稿。
- VMD 覆盖行业线索、竞品战卡、增长任务和结果复盘。
- 审批、项目和报表用于把建议变成受控业务动作并追踪结果。

## 8. 管理与可选模块

老板和管理员可查看 Agent 运行、成果质量、SLO、成本、权限矩阵、部署就绪和客户成功。完整调试 trace 不向普通员工默认开放。

HR、财务、OA、库存、资产、计费、插件、表单和工作流设计器默认不是首发主线。企业确有需求时由管理员启用，复杂专业流程优先连接已有系统。

## 9. 结果质量与安全

- 参数、法规、案例和竞品结论应能展开到企业资料来源。
- “待核验”表示证据不足，不应删除标记后直接外发。
- 付款、审批、删除、批量外发、会员和权限变更必须人工确认。
- 发现资料命中错误时，记录文档名、任务/成果 ID 和错误片段，并在成果中心提交反馈。
- 最终 Word/PDF 仍应由业务负责人检查品牌、数字、法律条款和签章内容。
