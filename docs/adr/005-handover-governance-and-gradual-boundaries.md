# ADR 005: 以可执行交接门禁推进渐进领域收敛

- 状态：Accepted
- 日期：2026-07-18

## 背景

项目由 AI 辅助快速扩展，功能覆盖广，但静态说明、文件规模、异常处理和领域所有权容易随迭代漂移。一次性重写会扩大回归风险，也无法保证新团队更容易接管。

## 决策

1. 使用生成式事实清单替代 README 中手写的页面、路由、工具和迁移数量。
2. 使用 `DOMAIN_REGISTRY` 登记渐进领域边界，不立即移动全部历史模块。
3. 对大型前端文件采用“契约测试 -> 等价抽取 -> 删除旧实现 -> 门禁锁定”的方式拆分。
4. 为宽泛异常捕获建立基线，只允许总量和分区数量下降。
5. CODEOWNERS、SLO、运行手册和销售实施清单作为正式交接资产进入 CI 检查。

## 后果

- 新团队可以从可执行证据理解系统，而不是依赖口头历史。
- 历史债务不会被一次消除，但不能继续无约束增长。
- 所有权变更和领域迁移需要同步更新 registry、文档和测试。
