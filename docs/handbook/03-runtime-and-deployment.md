# 运行时与部署

## 进程职责

| 进程 | 职责 | 可否水平扩展 |
|---|---|---|
| Web | FastAPI、SSE、认证与短用例 | 可以，保持无状态 |
| Worker | 长任务、集成同步、Agent 后台运行 | 可以，任务需幂等 |
| Beat | 周期调度 | 单逻辑实例，使用锁 |
| Redis | 队列、缓存、分布式锁 | 生产必需 |
| PostgreSQL | 业务状态、RLS、审计、向量 | 主数据源 |

## 发布顺序

1. 备份并验证恢复点。
2. 执行正向兼容迁移。
3. 部署后端，再部署前端。
4. 验证健康、认证、租户隔离、SSE 和一条黄金路径。
5. 观察错误率、P95、任务积压和 LLM 成本。

容器必须以健康检查而非“进程存在”判定就绪。多副本环境禁止在 Web startup 中启动重复调度器。
