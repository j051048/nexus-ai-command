# 安全与多租户

## 信任模型

客户端是不可信输入源。身份来自服务端验证后的 JWT；组织和权限由服务端上下文解析；数据库 RLS 是最终隔离层。Service Role 只允许在受控后台进程使用。

## 变更检查表

- 新表是否含标准租户列、RLS、策略和索引？
- 新 API 是否验证对象所属组织，而非只验证“已登录”？
- 新工具是否声明角色、风险、审计、幂等和 HITL？
- LLM 前是否最小化并脱敏上下文，输出后是否扫描泄露？
- 日志是否避开 Token、密码、原始 PII 和完整文档？
- 离线队列是否绑定用户与组织，登出后是否清除？

高风险动作包括付款、审批结论、删除、批量外发、会员权益和权限变更，默认需要二次确认和不可变审计。
