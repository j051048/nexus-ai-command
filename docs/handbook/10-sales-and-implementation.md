# 销售与实施交接

## 标准演示主线

以一家光谱/色谱/质谱/能谱或电子仪器企业为例，演示“线索进入 -> 客户画像 -> 竞品/投标分析 -> 跟进行动 -> 经营复盘”。不要把 OA、HR、财务页面数量作为主要卖点。

## 售前必须确认

- 客户组织结构、角色、数据地域和私有化要求。
- CRM/ERP/IM/文档系统及可用 API。
- 产品线、型号、应用场景、术语和投标证据来源。
- 预期自动化边界与必须人工确认的动作。
- 日活、并发、文档量、历史数据迁移和 SLA。

## 实施验收

每个客户建立隔离环境和黄金数据集。验收至少覆盖登录、组织隔离、知识检索、VMD 任务、CRM 跟进、投标分析、审计和备份恢复。任何“AI 准确率”承诺必须绑定数据集、版本和人工判定标准。
