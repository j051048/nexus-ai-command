# 销售与实施交接

## 标准演示主线

以一家光谱、色谱、质谱、能谱或电子仪器企业为例，演示“上传公司与产品资料 -> 验证 AI 可检索 -> 关联客户需求 -> 生成方案或审阅标书 -> 核验证据与承诺 -> 下载 Word/PDF/Excel -> 记录采用或赢单结果”。再补充线索、客户跟进和经营复盘，不把 OA、HR、财务页面数量作为主要卖点。

## 售前必须确认

- 客户组织结构、角色、数据地域和私有化要求。
- CRM/ERP/IM/文档系统及可用 API。
- 产品线、型号、应用场景、术语和投标证据来源。
- 企业模板、品牌规范、交付格式、审批人和哪些参数/承诺必须人工确认。
- 预期自动化边界与必须人工确认的动作。
- 日活、并发、文档量、历史数据迁移和 SLA。

## 实施验收

每个客户建立隔离环境和黄金数据集。验收至少覆盖登录、组织隔离、企业资料上传与入库、按文件名/语义检索、VMD/CRM 跟进、方案或投标深度生成、质量复核、持久化下载、审计和备份恢复。任何“AI 准确率”或“精品成果”承诺必须绑定资料集、模板、模型/Prompt 版本、质量门和人工判定标准。
